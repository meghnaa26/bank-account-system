# Bank Account System

A terminal-based banking system built with Python.

## Features
- Create bank account with auto-generated account number
- Secure PIN login system
- Deposit money
- Withdraw money (with balance check)
- Check balance
- View transaction history
- Transfer money between accounts
- All data saved automatically to JSON file

## How To Use
1. Run the program
2. Create an account
3. Note your account number and PIN
4. Login to access your account
5. Use the menu to manage your finances

## Built With
- Python 3
- JSON for data storage
- datetime for transaction timestamps
- random for account number generation
